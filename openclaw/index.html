OpenClaw

A personal assistant that reads and manages one person's Google Calendar.

What it is

OpenClaw is a private tool built and used by Dev Nambiar. It helps me keep my own schedule in order: it looks at my calendar, answers questions like "what's on Thursday?", and adds or moves events when I ask it to.

It isn't a public product. There's no sign-up, and nobody except me uses it.

Why it asks for Google Calendar access

To do its job, OpenClaw signs in to my Google account through Google's standard OAuth screen and asks for permission to use Google Calendar. It uses that permission to:

  • Read my calendars and events, so it can tell me what's coming up.
  • Create, edit and delete events on my calendar when I tell it to.

It doesn't touch Gmail, Drive, contacts or anything else in the account. Calendar data is used only to run these features for me. It isn't sold, shared or used for advertising.
